# AI 人工智慧應用與程式開發歷屆甄試複習系統 (AI Practice & Exam System)

本專案是一款專為 **「AI 人工智慧應用與程式開發（幼獅）」** 歷屆甄試筆試所設計的**無伺服器（Serverless）、單一 HTML 檔案、極致視覺與交互體驗**的學習與模擬測驗系統。

本系統完整收錄了 **113 年、114 年、115 年共三個年度、總計 150 道甄試考古題（智力測驗 75 題 + 專業科目 75 題）**。所有題目皆內置詳細的步驟拆解與考點分析，並具備易錯題標記、歷史作答進度動態記錄、側邊抽屜式題號導覽、防背題選項洗牌以及完全離線運作等功能。

---

## 🌟 核心功能特點 (Core Features)

### 1. 三大靈活學習與考試模式
- **平常練習區 (Practice Mode)**：
  - 獨立劃分 113、114、115 三個年份。
  - 各年份精確拆分為 **「智力測驗 (1-25 題)」** 與 **「專業試題 (26-50 題)」** 子分類。
  - 支援關鍵字搜尋（即時篩選題目、程式碼或選項）與「已標記易錯題」篩選。
  - **「重新作答」機制**：可一鍵重置單題作答狀態，隨時重新練習。
- **分年模擬考區 (Annual Mock Exam)**：
  - 選擇單一年度進行全真模擬，系統隨機自該年度抽選 25 題智力測驗與 25 題專業科目（共 50 題，滿分 100 分）。
  - 提供**打亂選項順序（Option Shuffling）**開關，徹底防止因死記 (A)(B)(C)(D) 位置而降低學習效果。
- **總模擬考區 (Overall Mock Exam)**：
  - 跨年度混合大考！系統隨機自 113 至 115 三年共 150 題庫中，嚴格依 1:1 比例（25 題智力 + 25 題專業）抽選並組合成 50 題全新試卷，適合考前沖刺。

### 2. 左側可收合學習進度與導覽側欄 (Collapsible Side Menu Drawer) — *V3.6 新增*
- **毛玻璃懸浮式面板 (Glassmorphic Drawer)**：採用 `fixed` 懸浮定位，預設收合於左側螢幕邊緣，點擊「拉把按鈕」平滑滑出。自動適應亮色、深色、護眼主題，且**完全不破壞**主內容區 30px 精確左右留白佈局。
- **四色學習進度追蹤**：依據當前選取的年份與分類，自動渲染 25 或 50 顆題號小圓點，實時同步 `localStorage` 中儲存的作答軌跡：
  - <kbd>🟩 淺綠色</kbd> ：**答對**（初次嘗試即正確）。
  - <kbd>🟥 紅色</kbd> ：**答錯**（作答錯誤）。
  - <kbd>🟧 亮橘色</kbd> ：**已改正**（*特色功能*！曾經答錯，重置並重新作答正確，提醒您此題曾錯但已改正，需特別注意）。
  - <kbd>⚪ 灰色</kbd> ：**未答**（尚未看過或點選）。
- **進度儀表板**：實時更新完成度（%）、答對題數、曾答錯/改正數、以及當前已答量。
- **平滑跳轉與焦點引導 (Smooth Scroll & Flash Focus)**：點擊側欄題鈕，頁面將流暢捲動至該題卡，且目標題卡會觸發 **藍色外框短暫閃爍動畫**，引導視線瞬間鎖定！

### 3. V3.4 佈局與 PDF 1:1 學術感答案隱藏機制
- **核心容器規格**：主內容區嚴格遵循 `width: calc(100% - 60px); margin: 20px auto; max-width: none;`，以實現全屏外擴與縮放時 5px 固定間隙的流暢位移。
- **正確答案隱藏欄**：符合 **純白背景、綠色文字 (#198754)、左側 5px 綠實線** 的專業學術風格。預設為字體與背景同色（白底白字，視覺隱藏），滑鼠移入（Hover）或反白選取（Selection）時自動顯現，在平常練習時能自我防雷。
- **去粉紅程式碼樣式 (Anti-Pink Syntax Styling)**：所有 C++、C# 等程式碼塊，均使用高質感的深色灰炭底色 (`#1e293b`) 與亮灰字體 (`#e2e8f0`)，嚴格杜絕任何粉紅色文字與背景，保障專業工程美感。

### 4. 易錯題持久化 (Flagging & Persistence)
- 每道題目均有「標記為易錯題」的旗標鈕。點擊後，題卡外框變為醒目的橘色，並加上「易錯題」微型標籤。
- 所有標記狀態、主題設定與答題歷史均通過 `localStorage` (`flagged_questions`、`practice_history`、`review_system_theme`) 存儲於瀏覽器，**離線、重新整理或關閉網頁皆不遺失數據**。

### 5. 複雜幾何圖形原生向量繪製 (Pixel-Perfect Inline SVGs)
- **114 年 Q6**：以原生 CSS 與 SVG 完美呈現循環圖形規律（田、ʘ、日、Ө、Bowtie、Crossed-Square、▲）。
- **114 年 Q9**：精確繪製三角柱展開圖向量網格（包含頂點標記 A~J 與面標記 ㄇ、ㄈ、ㄅ、ㄉ、ㄆ）。
- **115 年 Q6**：以多合一 SVG 網格對照呈現正方形對角線的幾何特徵，並與官方公佈之標準答案（B）完全對接。

## 🛠️ 專案技術規格 (Technical Specifications)

- **核心架構**：單一檔案自包含 (Self-contained Single-file HTML)。
- **技術棧**：HTML5 + 原生 CSS3 (Flexbox, Grid, CSS Variables) + 原生 JavaScript (ES6+)。**無任何外部套件依賴 (Zero Dependencies)，無 Tailwind，無 JS Framework，雙擊即可執行！**
- **相容性標準**：
  - 符合 **V3.1 「去粉紅」程式碼規則** 與「純白背景、綠色文字、5px左綠實線」隱藏答案欄。
  - 符合 **V3.4 題目容器計算公式布局標準**。
  - 符合 **V3.6 懸浮抽屜式側進度選單與歷史狀態追蹤標準**。

## 🚀 快速開始 (Quick Start)

### 1. 執行複習系統
本系統完全不需要安裝任何環境、伺服器或依賴套件。
1. 將本專案複製或下載至您的電腦。
2. 在 `AI_TEST` 目錄下，**直接雙擊 `index.html`**，即可使用您的預設瀏覽器（推薦 Chrome、Edge、Safari 或 Firefox）開啟並開始複習！

### 2. 側選單與作答指示
- 開啟「平常練習區」時，螢幕左側會出現一個帶有 `📊` 的懸浮拉把。
- 點選拉把即可滑出進度面板，您可以一邊看題目一邊作答。
- 作答後：
  - **綠色**代表您答對了，**紅色**代表答錯。
  - 若答錯了，您可以點選該題卡下方的 **「🔄 重新作答」** 按鈕以清除鎖定。
  - 當您再次嘗試並答對後，側欄的對應題號會由紅色升級為**橘色（已改正）**，方便您在考前特別針對這些「曾錯題」進行高效率重溫！
- 您隨時可以在側欄點擊任何題號，頁面會自動以平滑的動畫滾動到該題目。

## ⚠️ 團隊開發與 Git 協作規範 (Git & Developer Rules)

為了維護本專案的穩定性與技術文件完整性，所有協作的 AI 開發代理人與工程師必須嚴格遵守以下開發禁忌與原則：

1. **嚴格禁止自動 Git Commit**：
   - **絕對禁止**在程式碼修改後自動執行 `git commit` 或 `git push` 指令。
   - 所有程式碼變更必須先由使用者在本地環境進行多模式、多主題的實際交互測試，確認無誤後，**必須在得到使用者明確口頭指示「可以提交」或「commit」之後**，方可進行 Git 提交流程。
2. **修改前強制備份規範**：
   - 在對專案主檔案 `index.html`（或任何 JS/HTML/JSON 檔案）進行任何結構性或邏輯性修改之前，**必須**先將目前的檔案複製一份，備份至根目錄的 `backups/` 資料夾中（統一使用 `.bak` 後綴），以確保若編碼發生錯誤或運行出錯時能隨時進行秒級還原。
3. **Git 指令操作禁忌**：
   - 執行 Git 狀態查詢時，**嚴禁**將 `git status`、`git diff`、`git log` 串聯在同一行指令中執行（如 `git status && git diff HEAD`），避免大型輸出導致終端機或系統當機。
   - `git diff` 應優先使用 `--stat` 以獲得精簡的輸出。
   - `git log` 的終端機輸出應加上數量限制（如 `git log -n 3`），保持簡潔。
4. **CSS 佈局與樣式邊界限制**：
   - 題目容器的 `width: calc(100% - 60px); margin: 20px auto; max-width: none;` 是核心排版代碼，**嚴禁修改**。
   - 答案遮罩 bar 的 **「去粉紅」** 與 **「純白背景、綠色文字 (#198754)、左側 5px 綠實線」** 是學術感PDF 1:1 復刻標準，**嚴禁私自優化或加入彩色底色**。
